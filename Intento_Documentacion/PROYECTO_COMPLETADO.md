## 🏗️ ARQUITECTURA ANALIZADA

### 7 Nodos Especializados

```
[1] ASISTENTE REQUISITOS
    ├─ Extrae criterios del texto libre
    ├─ Usa GPT-4o con prompt especializado
    └─ Valida criterios

[2] COORDINADOR
    ├─ Define zonas de búsqueda
    ├─ Usa GPT-4o-mini para análisis
    └─ Registra en historial

[3] AGENTE NOTICIAS
    ├─ Busca noticias reales
    ├─ Analiza compatibilidad de zonas
    └─ Genera análisis con LLM

[4] SCRAPING
    ├─ Busca en múltiples portales
    ├─ Elimina duplicados
    └─ Modo simulado para testing

[5] EVALUADOR
    ├─ Califica propiedades (scoring)
    ├─ Aplica bonus/penalización por zona
    └─ Genera explicación narrativa

[6] RELAJACIÓN
    ├─ Modifica criterios de forma gradual
    ├─ Respeta orden de prioridad
    └─ Registra cambios en historial

[7] VALIDADOR
    ├─ Validación final de coherencia
    ├─ Reglas específicas del mercado
    └─ Genera veredicto
```

- **OpenAI**: GPT-4o y GPT-4o-mini

## 🚀 CÓMO USAR EL PROYECTO

### Instalación Rápida

```bash
# 1. Clonar repositorio
git clone https://github.com/tu-usuario/recomendacion_vivienda.git
cd recomendacion_vivienda

# 2. Crear entorno virtual
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Configurar variables de entorno
cp .env.example .env
# Editar .env con tus claves API

# 5. Ejecutar
python main.py
```

### Uso Básico

```python
from main import ejecutar_sistema

input_usuario = "Busco apto en El Poblado, máximo 400M, 2 cuartos"
resultado = ejecutar_sistema(input_usuario)
```

### Acceder a Documentación

```bash
# Leer documentación principal
cat ARQUITECTURA_SISTEMA.md

# Ver diagramas
cat DIAGRAMA_DETALLADO.md

# Resumen ejecutivo
cat RESUMEN_EJECUTIVO.md
```
